# 원격에서 보는 사용자

사용자는 다른 기기(태블릿 등)에서 접속한다. 이 머신의 화면, `localhost` 주소, 로컬 파일은 볼 수 없다.

- `localhost:포트` 주소, 로컬 파일 경로, 로컬 파일 첨부로 결과를 안내하지 않는다.
- 보여 줄 것이 생기면 아티팩트로 올리고 링크를 준다. 갱신할 때는 같은 파일 경로로 다시 올려 링크를 유지한다.
- 이미지는 HTML 안에 base64 `data:` URI 로 넣는다. 인코딩은 파이썬 같은 스크립트로 하고, base64 문자열을 대화에 올리지 않는다.
- 화면 캡처는 2배율(레티나)로 찍는다. 1배율 캡처는 글자가 뭉개져 차이를 눈으로 확인할 수 없다.
