# 코드 색인(codegraph) 설치

이 머신에는 codegraph 가 없다. 코드 흐름·호출처·변경 영향을 볼 일이 생기면 사용자에게 묻고 멈추지 말고 설치·초기화한 뒤 계속한다.

1. `which codegraph || brew install codegraph` 로 설치한다(macOS 기준, 다른 환경은 그 패키지 관리자).
2. 저장소 루트(또는 작업 중인 워크트리)에서 `codegraph init .` 를 한 번 실행한다. 색인 만들기는 무거운 실행이라 `wb-slot` 안에서 돌린다.
3. 워크트리에서 질의할 때는 `projectPath` 에 그 워크트리 경로를 넘긴다. 넘기지 않으면 빈 결과가 나온다.
4. 설치할 수 없는 환경이면 grep 과 Read 로 진행하고, 설치하지 못한 이유를 보고에 적는다.
