# 코드 색인(codegraph) 설치

이 머신에는 codegraph 가 없다. 직접 설치하지 말고 `rg` 와 Read 로 계속 진행한다.

1. 코드 흐름·호출처·변경 영향을 보려면 검색이 많이 필요할 수 있다. 그럴 때는 codegraph 가 없다는 사실을 사용자에게 한 번 알리고, 설치 명령 `brew install codegraph` 를 보여 준다(macOS 기준이며, 다른 환경은 그 시스템의 패키지 관리자를 쓴다).
2. 사용자가 자기 메시지로 동의했을 때만 설치한다. 설치한 다음에는 저장소 루트(또는 작업 중인 워크트리)에서 `codegraph init .` 를 한 번 실행한다. 색인 만들기는 무거운 실행이라서 `lanekeeper-slot` 안에서 돌린다.
3. 워크트리에서 질의할 때는 `projectPath` 에 그 워크트리 경로를 넘긴다. 넘기지 않으면 빈 결과가 나온다.
4. 사용자가 거절했거나 설치할 수 없는 환경이면 `rg` 와 Read 로 계속하고, 이 세션에서 다시 묻지 않는다.
