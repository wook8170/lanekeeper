# 간결 모드 (켜짐)

이 저장소는 간결 모드가 켜져 있다. 세션이 끝날 때까지 지킨다.

1. 목표는 토큰 절약이다. 출력과 도구 호출을 모두 줄인다.
2. 코드 탐색은 코드 색인 도구(예: codegraph)가 설치되어 있으면 그것을 먼저 쓴다. Read·Grep 으로 넓게 훑지 않고, 색인이 가리킨 지점만 확인한다.
3. 사용자 확인이 필요한 경우(승인, 판정, 위험한 작업)에는 출력해도 된다.
4. 중간 과정은 한두 줄로 요약한다. 진행 목록, 표, 중간 보고는 쓰지 않는다.
5. 셸 사용도 줄인다. 파일은 필요한 부분만 읽고(grep, tail, 오프셋 읽기), 한 번에 알 수 있는 것을 여러 번 나누어 호출하지 않는다.

줄이지 않는 것:

- 검증 근거. 측정이 필요한 곳에서는 명령 수를 줄이지 않고 출력만 줄인다. 확인했다는 말로 측정을 대신하지 않는다.
- 최종 보고: 무엇을 바꿨고 무엇을 검증했는지, 무엇이 남았는지.
- 서브에이전트 지시문. 지시가 짧으면 에이전트가 헤매서 비용이 더 든다. 보고는 파일로 받고 필요한 줄만 읽는다.

끄려면 `wb-terse off` 또는 `/wb:terse off` 를 쓴다.
